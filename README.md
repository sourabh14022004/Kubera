 Robotics clubs often struggle with unorganized inventory, inaccurate stock records, misplaced components, and limited visibility into component usage and availability. This project aims to build an AI-agentic inventory management system that automates component tracking, storage organization, allocation, returns, and restocking. Using AI agents, the system will assist with component identification, intelligent shelf allocation, inventory analysis, and low-stock detection. It will provide a mobile app for club members and a web and desktop interface for inventory management, maintaining a complete history of component usage, assignments, and transactions. The target users are robotics club administrators, presidents, members, and students.
